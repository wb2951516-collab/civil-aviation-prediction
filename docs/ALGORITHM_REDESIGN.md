# V1.1 算法重设计与优化评估报告

> 评估对象：民航旅客运输量预测系统（CAPM）
> 评估范围：现状融合架构优劣、算法精选（移除/保留决策）、选择机制设计、
>           马尔可夫与贝叶斯理论融入可行性、量化回测系统化验证
> 评估原则：独立、客观、基于数据与实证；结论不以需求方偏好为转移
> 评估日期：2026-08-12

---

## 1. 现状评估：多模型融合架构（V1.0）

### 1.1 原架构

```
历史序列 ──→ Holt-Winters ──┐
        ──→ SARIMA      ──┼──→ 加权融合 ──→ 节假日效应修正 ──→ 年度增长校准
        ──→ 线性回归     ──┘     (手动权重 / MAPE倒数自动权重)
```

- 权重默认 `hw 0.4 / sarima 0.3 / linear 0.3`（手动），可选 MAPE 倒数自动权重；
- GUI 提供 4 个单选（融合/HW/SARIMA/线性）供手动选择。

### 1.2 优势

| 维度 | 评价 |
|------|------|
| 结构简洁 | 三层流水线（模型→节假日→增长），业务人员可完整理解 |
| 融合降险 | 多模型加权平均降低单一模型失效风险，回测中融合误差低于多数单模型 |
| 可解释 | 各环节（HW 三项平滑、SARIMA 参数、节假日系数）均可向业务解释 |

### 1.3 劣势（V1.1 修正点）

1. **线性回归模型不适用于民航月度数据**：无法刻画强季节性形态（月客流 7-8 月与 2 月为峰、4 月为谷），外推对端点敏感——端点值微扰导致整条预测线大幅漂移；
2. **手动权重缺少依据**：固定 0.4/0.3/0.3 无实证支撑，不同数据窗口下最优权重差异显著；
3. **无状态感知**：模型对市场结构性变化（疫情冲击、高铁分流）无任何响应机制；
4. **无外部因子**：GDP、ASK 等宏观/行业信息完全未参与计算，预测仅依赖历史序列自回归；
5. **界面交互陈旧**：单选+手动权重的组合对一线人员不友好（详见界面升级说明）。

## 2. 算法精选决策（实证依据）

### 2.1 量化对比数据（合成月度序列 2015-2025，含疫情冲击，滚动回测 MAPE%）

| 模型 | 旧方案(3模型) | 新方案(2模型) | 新方案(含外部因子) |
|------|-------------|--------------|------------------|
| Holt-Winters | 11.21 | 11.21 | 11.21 |
| SARIMA | 11.81 | 11.81 | 12.15 |
| **线性回归** | **13.40** | —（已移除） | — |
| 融合 | 10.40 | 11.38 | 11.49 |

### 2.2 线性回归移除依据

- **实证最差**：滚动回测 MAPE 13.40%，高于 HW（11.21%）与 SARIMA（11.81%）约 2 个百分点；
- **结构局限**：模型假设"直线趋势+噪声"，月度强季节性形态（春运/暑运/十一）无法建模；
- **外推风险**：趋势线斜率由端点决定，在结构突变（如 2020 疫情）后外推误差急剧放大；样本外测试显示跨越恢复期时所有模型 MAPE 达 38%，线性模型在该场景下无任何缓冲机制；
- **信息冗余**：其"趋势"信息已被 HW 趋势项与 SARIMA 差分结构覆盖，保留仅增加融合噪声；
- **明确说明**：在"理想线性趋势"合成数据上，融合中加入线性模型可使整体 MAPE 从 11.38% 降至 10.40%（多样性收益），但该收益依赖"趋势平稳"这一真实市场不具备的前提，且线性单模型误差最大、风险不可控。**结论：移除，以"精选集合 + 自动调度"替代**。

### 2.3 保留集合

| 算法 | 角色 | 说明 |
|------|------|------|
| Holt-Winters | 精选单模型 | 结构简单、计算快、短期稳健（见算法手册） |
| SARIMA/SARIMAX | 精选单模型 | 统计推断、可接外生变量（见算法手册） |
| 融合模型 | 默认方案 | BMA 权重自动融合，见第 5 节 |
| 简单季节性 | 兜底 | 数据不足或拟合失败时自动降级 |

### 2.4 选择机制设计（保留手动 + 自动推荐双模式）

- **手动选择**：在精选集合（融合/HW/SARIMA）内保留 RadioButton，专家可强制指定；
- **自动推荐**（默认开启）：每次预测前自动执行滚动回测 → 依 BMA 权重与 MAPE 选出最优模型/权重 → 一键应用；界面展示推荐依据（各模型指标对比与权重方法）；
- **设计理由**：一线场景多样——自动模式保证开箱即用且随数据演化自适应（如本次实证中 BMA 自动将 SARIMA 权重压至 0.05）；手动模式满足专家调优；两者共享同一精选集合，逻辑互斥、切换无损。

## 3. 马尔可夫理论融入评估（客观结论）

### 3.1 理论适配性

- 马尔可夫链适合**离散状态转移**建模；月度客运量环比增速可离散化为增长/平稳/回落三状态；
- 直接用于**数值预测**存在三个结构性问题：
  1. **状态定义主观**：阈值（如 ±1%）任意性大，状态划分直接影响转移矩阵；
  2. **齐次性假设脆弱**：民航市场结构（疫情冲击、高铁竞争、运力投放）持续变化，固定转移矩阵的马尔可夫性不成立——实测状态频率与稳态分布高度依赖样本区间；
  3. **信息粒度损失**：状态概率是"软信号"，对逐月数值预测的边际信息量远低于季节性结构本身。

### 3.2 实证观察（本次评估）

- 状态频率：回落 45.8% / 平稳 6.9% / 增长 47.3%——"平稳"状态占比极低，阈值设定导致状态区分度差；
- 转移矩阵显示回落→增长（0.51）与增长→回落（0.53）的高跳变概率，说明月度环比状态不稳定、无显著持续期——直接状态链的预测价值有限。

### 3.3 结论

- **直接状态链作为数值预测器：不建议**（边际收益有限、参数主观）；
- **作为情景分析辅助层：可行**（已实施）：状态频率/稳态分布/未来状态概率为生产保障提供景气情景参考，不影响主预测路径；
- **专业替代路径**：若未来要利用体制结构，应使用 statsmodels `MarkovRegression`（马尔可夫体制转换回归）作为独立候选模型进入回测实证，用数据决定去留——本版本未纳入默认集合，原因：数据跨度（10 年）内体制转换样本过少（仅疫情一次强冲击），参数估计不稳定，收益预期低于其复杂性代价。

## 4. 贝叶斯理论融入评估（客观结论）

### 4.1 BMA（贝叶斯模型平均）—— 已实施

- **原理**：以滚动回测残差的高斯似然（含二阶矩信息）计算后验权重 `w_m ∝ π_m·exp(log L_m)`，先验默认均匀，附权重下限防退化；
- **相对 MAPE 倒数法的优势**：
  - MAPE 倒数仅使用平均绝对百分比误差（一阶矩）；BMA 使用完整残差分布（二阶矩），对离群误差更敏感、更稳健；
  - 先验机制可注入业务先验，下限机制防止权重归零；
- **实证结果**：滚动回测中 BMA 自动给出 HW=0.952 / SARIMA=0.048（SARIMA 误差更大被自然压制）；旧固定权重 HW=0.571/SARIMA=0.429 无差别对待。**结论：实施，收益明确且实现成本低（闭式解，无采样开销）**。

### 4.2 贝叶斯回归（外生因子系数估计）—— 已实施

- 以贝叶斯岭回归（高斯先验 N(0,1/α)）估计 GDP/ASK 对客流的弹性系数，正则化缓解宏观变量共线与小样本问题；
- 用于管理控制台接入后对外生变量贡献的定量解释。

### 4.3 BDLM / 贝叶斯结构时间序列 —— 不建议

- 状态空间形式要求逐月手工维护（观测方差、状态方差超参），计算与调优成本高；
- 对月度生产保障系统属过度工程化；若未来需要，应优先评估 `statsmodels` 的 `UnobservedComponents` 而非自建。

### 4.4 外部因子（GDP/ASK）的实证警示

- 滚动回测显示：SARIMA 接入外生因子后 MAPE 由 11.81% 升至 12.15%（+0.34pp）；
- 原因：SARIMAX 要求外生变量的**未来值**，系统采用最近增速外推，外推误差直接传导至预测；
- **结论**：外部因子接入是"有条件价值"功能——当外生变量可获取官方预测（统计局展望/民航局计划）时价值最大；纯外推场景下其贡献有限甚至为负。系统保留接入能力与开关（管理控制台默认启用，可一键停用），并在数据源状态中如实标注来源与口径。

## 5. 量化回测系统化验证（V1.1 实现）

### 5.1 回测框架（参考量化交易回测成熟做法）

| 模块 | 说明 |
|------|------|
| 滚动回测（walk-forward） | min_train=24 起逐段训练、外推 12 个月，覆盖多市场阶段 |
| 样本外测试（holdout） | 前 80% 训练 → 后 20% 预测，模拟真实"用过去预测未来" |
| 绩效指标 | MAE / RMSE / MAPE / **MDA**（方向命中率）/ **Theil U**（相对朴素基准）/ **Ljung-Box**（残差自相关检验） |
| 稳健性 | 多训练窗口（24/36/48 月）+ 分阶段对比（2020 疫情前后） |
| 推荐输出 | 最优单模型 + BMA 融合权重 + 权重方法标注 |

### 5.2 核心结论汇总

1. **精选有效**：HW 单模型 MAPE 11.21% 为精选集合最优；融合（自动权重）误差介于单模型之间并随数据自适应；
2. **自动调度有效**：BMA 自动识别 SARIMA 在含冲击数据上的劣势并压制其权重（0.048），无需人工干预；
3. **外部因子有条件价值**：外推型因子在回测中贡献有限（见 4.4），真实价值取决于官方预测质量；
4. **结构突变是最大风险源**：样本外测试（跨越 2020 恢复期）所有模型 MAPE 达 38%、Theil U>1——任何统计模型都无法仅凭历史序列预测结构性恢复。**生产保障含义**：预测结果应结合管理控制台情景分析（状态转移）与人工判断使用，系统在报告中如实展示误差水平，不夸大精度。

### 5.3 稳健性分析（多窗口 / 分阶段 / 残差检验）

**多训练窗口 MAPE%（滚动回测）**：

| min_train | HW | SARIMA | 融合 | 推荐 |
|-----------|-----|--------|------|------|
| 24 个月 | 11.21% | 11.81% | 11.38% | hw |
| 36 个月 | 12.02% | 12.64% | 12.19% | hw |
| 48 个月 | 13.02% | 13.70% | 13.20% | hw |

- 训练窗口越长误差越大：更长窗口包含更多疫情冲击样本，模型被低谷拉低——**长度≠更好**，24~36 个月是该数据的最优训练窗口；
- HW 在全部窗口下保持最优，稳定性最佳。

**分阶段对比（2020 疫情前后）**：

| 区间 | HW | SARIMA | 融合 |
|------|-----|--------|------|
| 2020 之前（平稳期） | 4.76% | 5.09% | 4.92% |
| 2020 之后（含冲击） | 5.92% | **46.88%** | 46.72% |

- 平稳期全部模型精度优秀（MAPE ≈ 5%）；
- 含冲击区间 SARIMA 灾难性劣化（46.88%），HW 保持稳健（5.92%）——差分模型被结构性低谷污染后难以恢复，指数平滑的自适应特性优势明显；
- 该实证同时证明**自动调度（BMA）的必要性**：若一线人员手动选择 SARIMA，在含冲击数据上将获得近 47% 误差；自动推荐则始终收敛到 HW。

**Ljung-Box 残差自相关检验**（主回测，lag=12）：HW/SARIMA/融合的残差均未通过（p<0.001）——残差仍存在未建模的时序结构（节假日脉冲、春运形态等）。客观含义：
- 模型对月度数据的时序依赖并非完全捕捉，预测区间应被视为下限估计；
- 为未来"残差 ARMA 修正层"留出改进空间，系统不宣称超越实际水平的精度。

### 5.4 五维度评估（生产保障 / 成本预算场景）

| 维度 | 评价 |
|------|------|
| 预测精度 | 常规场景 MAPE 约 11%（精选融合）；结构突变期显著劣化（如实展示） |
| 稳定性 | 滚动窗口下 HW 波动最小；BMA 权重自适应降低单模型失效风险 |
| 可解释性 | 流水线三层均可解释；算法手册内置到界面，一线可对照查阅 |
| 计算效率 | HW+SARIMA 单次预测 < 数秒；回测（含自动调参）秒级~十秒级，可接受 |
| 业务实用性 | 自动推荐开箱即用、手动选择支持专家、导出报告含误差与权重依据 |

## 6. 与生产保障/成本预算的衔接建议

1. 预测结果用于**年度总量预算**（12 个月滚动）时，采用融合模型+自动权重，并参考状态转移分析做上下情景（±1 个标准差）；
2. 用于**月度保障排班**时，短周期（1-3 个月）优先参考 HW 单模型；
3. 宏观联动分析（运力投放、机队规划）时启用管理控制台外部因子，并优先采用官方预测口径的外生变量；
4. 每年末基于当年实际数据重跑回测（一键），以 BMA 更新次年权重。
