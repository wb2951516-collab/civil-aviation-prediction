# V1.4 卡尔曼滤波融入：严格门槛验收报告

> 评估日期：2026-10-03 · 结论：**通过门槛，卡尔曼成员默认启用**（Phase 2 自适应融合器未通过，不采纳）
> 复现脚本：`evaluation/gate_eval.py` · 原始数据：`evaluation/results/baseline.json`、`evaluation/results/gate.json`

## 一、背景与方案取舍

现有 SARIMA/SARIMAX 在 statsmodels 的 statespace 引擎中**本身就以卡尔曼滤波做参数估计与状态递推**，因此"在预测链路上再套一层卡尔曼"没有意义。V1.4 的评估对象是三种真正可能带来增益的融入方式：

| 方案 | 内容 | 结论 |
|------|------|------|
| A | 新增显式状态空间模型（UC：局部线性趋势 + 随机季节）作为**第三集成成员**，纳入回测与 BMA 权重体系 | **采纳** |
| B（Phase 2） | 用卡尔曼滤波在线自适应地更新组合权重（Granger-Ramanathan 状态空间形式）替代静态 BMA 权重 | 回测劣化，**不采纳** |
| C | 仅对输出做 KF 平滑/校正层 | 不引入新信息，未评估 |

## 二、评估协议

- **主评估序列**：CAAC 官方月度客座率（akshare `macro_china_passenger_load_factor`），2006-02 ~ 2026-08 共 247 个月，含春运/暑运季节性、长期趋势与 2020 疫情结构断点；个别缺失月按时间插值补齐。
- **稳健性序列**：内置 ASK 月度近似序列（2015–2025，132 个月；不喂同源外生变量以避免数据泄漏）。
- **回测协议**：与应用"自动推荐"完全一致的 `rolling_backtest(horizon=12, step=12, min_train=24, engine="intervention")`，共 18 个滚动窗口（2008-02 ~ 2026-01）。
- **指标**：MAPE / RMSE / MDA / Theil U / Ljung-Box 残差检验。
- **验收门槛（事先约定）**：三成员集成 MAPE 相对两成员基线**相对改善 ≥3% 或绝对改善 ≥0.3 个百分点**，达标才默认启用；否则仅作为可选模型保留。

## 三、主评估序列结果（CAAC 客座率，247 个月）

| 模型 | MAPE | RMSE | MDA | Theil U |
|------|------|------|-----|---------|
| Holt-Winters | 4.54% | 3.887 | 0.707 | 1.343 |
| SARIMA(干预) | 4.47% | 3.942 | 0.712 | 1.278 |
| 卡尔曼 UC(干预) | 12.80% | 10.406 | 0.601 | 3.614 |
| **两成员集成（V1.3 基线）** | 4.023% | 3.479 | 0.722 | 1.149 |
| **三成员集成（V1.4）** | **3.608%** | **3.165** | **0.722** | **0.990** |

**门槛判定：相对改善 10.32%，绝对改善 0.415pp → 通过**（两个判据均满足）。

要点：

1. 卡尔曼**单模型**误差明显高于 SARIMA（12.8% vs 4.5%），BMA 自动将其权重压缩至下限附近（推荐权重约 HW 0.046 / SARIMA 0.908 / 卡尔曼 0.046）；但即便如此，三成员集成的 MAPE/RMSE/Theil U 全面优于两成员集成——改善来自**模型多样性**而非卡尔曼自身精度。
2. 三成员集成 Theil U 从 1.149 降至 **0.990**，跨过"优于朴素基准"的界线。
3. Ljung-Box 检验提示三成员残差仍含自相关结构（p<0.05），与基线一致，非本次引入的退化。

## 四、稳健性序列结果（内置 ASK，132 个月）

两成员基线 MAPE 31.97% → 三成员 27.14%（相对改善 15.09%）→ **同样通过**。
（注：该序列 2020 年断点幅度为真实量级的数倍，属病态压力场景，SARIMA 干预模型在其上表现剧烈波动；仅作稳健性参考。）

## 五、Phase 2：KF 自适应融合器（不采纳）

以组合权重为状态、按月序贯卡尔曼更新（无前视泄漏，融合发生在观测真实值之前）：

| 方案 | MAPE | RMSE | Theil U |
|------|------|------|---------|
| 三成员 + 静态 BMA 权重 | **3.608%** | **3.165** | **0.990** |
| 三成员 + KF 自适应权重 | 4.220% | 4.990 | 1.400 |

KF 自适应融合器相对静态 BMA **劣化约 4.9%**（月度数据仅 18 个窗口，在线权重学习样本不足，且过程噪声引入额外方差）。结论：**静态 BMA 已是当前样本量下的更优选择**，Phase 2 代码保留在评估脚本（`evaluation/gate_eval.py::kf_adaptive_fuse`）中供未来更长序列复验，不进入应用。

## 六、V1.4 默认策略（依据门槛结果）

- 默认融合权重 `{"hw": 0.4, "sarima": 0.4, "kalman": 0.2}`；"自动权重(回测)"模式下由 BMA 重新自适应分配；
- 卡尔曼权重 > 0 时自动纳入回测成员池；置 0 即完全恢复 V1.3 两成员行为（老配置文件兼容，缺失键按 0 处理）；
- UI 新增"卡尔曼滤波"单模型选项、融合权重第三输入框、"卡尔曼自动调参"开关与算法手册条目。

## 七、复现方式

```bash
# 在项目根目录（需联网抓取 CAAC 数据；离线时仅跑内置 ASK 稳健性序列）
python -m evaluation.gate_eval baseline       # 两成员基线
python -m evaluation.gate_eval gate --phase2  # 三成员对比 + Phase2 KF融合器 + 门槛判定
```
