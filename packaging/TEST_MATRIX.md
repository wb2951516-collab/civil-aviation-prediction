# 安装包测试与验证清单

## 测试环境

- Windows 10 x64、Windows 11 x64
- macOS 最新两个版本：分别在 Intel 与 Apple Silicon（若需要双架构支持）
- Ubuntu LTS x86_64
- Fedora 最新版本 x86_64

## 测试项（每个平台都要做）

1. 纯净环境安装
   - 默认路径安装
   - 自定义路径安装（如支持）
   - 桌面快捷方式/启动器条目可用
2. 程序启动与核心功能
   - 启动无报错
   - 导入/录入 → 运行预测 → 图表渲染
   - 导出 Excel 生成成功
3. 静默安装（Windows）
   - `/SILENT` 与 `/VERYSILENT` 安装可用
4. 升级覆盖
   - 安装旧版本 → 安装新版本覆盖
   - 用户数据目录保留（配置不丢失）
5. 卸载
   - 主程序与快捷方式移除
   - 用户数据是否按预期保留/删除（Windows 安装时勾选“卸载时删除用户数据”则卸载后应清理）
6. 权限与系统集成
   - Windows：UAC 提权正常
   - macOS：签名与 Gatekeeper 检查通过（`spctl -a -vv`）
   - Linux：桌面菜单显示与启动正常（`.desktop`）

## 验收标准

- 安装/运行/卸载全流程无缺失文件、无路径错误
- 主功能可用且性能无明显退化
- 安装包包含版本信息与产品标识
